# 메타몽 데스크톱 러그 · Ditto Rug

Windows 바탕화면에 놓는 보송보송한 메타몽 러그입니다.

**[Windows x64 설치 파일 다운로드](https://github.com/WasJoy/rokeshot-rug/releases/latest/download/Ditto-Rug-1.4.1-win-x64.exe)** · [릴리스 및 검증 결과](https://github.com/WasJoy/rokeshot-rug/releases/latest)

## 설치

1. 설치 EXE를 내려받아 실행합니다.
2. 설치 위치를 선택하고 설치를 마칩니다.
3. 시작 메뉴 또는 바탕화면의 **Ditto Rug**를 실행합니다.

기존 ZIP 버전은 트레이 메뉴에서 종료한 후 새 버전을 실행하세요. 코드 서명 인증서가 없는 개인용 앱입니다. Windows가 게시자를 확인하지 못했다는 안내를 표시할 수 있습니다.

## 사용법

- 러그를 잡아 끌면 움직이고 가장자리가 접힙니다.
- 러그 위에서 마우스 휠을 돌리면 크기가 바뀝니다.
- **Ctrl + Shift + L**: 클릭 통과 잠금 / 잠금 해제
- 트레이 아이콘 메뉴: 숨기기, 보이기, 위치·크기 초기화, 종료
- 위치, 크기, 잠금 상태는 PC에 저장됩니다.

## v1.4.1 수정

러그 위에 마우스를 올릴 때 화면 전체가 검게 변하던 문제를 수정했습니다. Windows의 투명 창을 Explorer의 자식 창으로 바꾸지 않고, 바탕화면 바로 위에 배치합니다. 대비되는 바탕화면에서 호버·휠·잠금 전환의 배경색 유지와 일반 앱 뒤의 표시 순서를 검사합니다.

## v1.4.0 수정

Windows 시작 시 바탕화면 연결 코드가 필수 인수를 누락해 창이 나타나지 않던 오류를 수정했습니다. 시작 오류가 생기면 이제 오류 내용을 표시합니다.

검증 범위와 결과는 각 릴리스에 첨부하는 `validation-report.json`에서 확인할 수 있습니다. GitHub의 Windows 실행 환경에서 수행하는 검사이며 모든 Windows PC, 배율, 다중 모니터 구성의 동작을 보증하지 않습니다.

파일 정리나 이동을 수행하지 않는 시각적 바탕화면 오버레이입니다. Pokémon 공식 제품이 아닌 개인용 팬 프로젝트입니다.
